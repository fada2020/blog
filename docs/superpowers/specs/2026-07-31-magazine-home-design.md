# 기술 매거진형 홈 개편 설계

## 목표

현재 홈은 공개 글이 1개일 때 넓은 여백이 그대로 드러나 완성도가 낮아
보인다. 실제 발행된 글만 사용하면서도 기술 매거진처럼 밀도 있고 편집된
첫 화면을 제공한다.

## 원칙

- 존재하지 않는 글, 가짜 조회수, 임의의 인기 순위를 만들지 않는다.
- 공개 글만 대표 글과 최신 글에 사용한다.
- 학습 로드맵과 편집 원칙은 콘텐츠가 아니라 블로그 운영 정보로 구분한다.
- 기존 카테고리, 태그, 검색, 다크 모드와 `/blog/` 경로를 유지한다.
- 이미지와 타이포그래피가 첫 화면의 주된 시각적 신호가 되도록 한다.

## 데스크톱 구성

### 1. 매거진 헤더

기존 전역 내비게이션은 유지하되 홈 본문과 맞닿는 경계를 명확하게 만든다.
브랜드명과 메뉴가 대표 글보다 강하게 보이지 않도록 현재 크기 체계를
유지한다.

### 2. 대표 글

가장 최근에 발행된 글 1개를 대표 글로 사용한다.

- 왼쪽 또는 상단에 1200x630 대표 이미지
- 발행일, 글 유형, 카테고리
- 제목과 요약
- 상세 글로 이동하는 명확한 링크

대표 글은 카드 안에 또 다른 카드를 넣지 않고, 이미지와 텍스트가 하나의
편집 면을 이루도록 구성한다.

### 3. 관심 분야

`Backend`, `Frontend`, `DevOps`, `Observability` 네 영역을 짧은 설명과 함께
노출한다. 실제 카테고리가 존재하면 카테고리 페이지로 연결하고, 아직
존재하지 않으면 링크 없이 블로그가 다룰 주제 범위만 설명한다.

### 4. 최신 글

대표 글을 제외한 공개 글을 최신순으로 표시한다. 글이 없으면 빈 카드나
가짜 글을 만들지 않고, 앞으로 발행될 글을 기다리는 짧은 상태 문구를
표시한다.

각 글 항목은 다음 정보만 포함한다.

- 작은 대표 이미지
- 발행일과 카테고리
- 제목
- 한 줄 요약
- 태그

### 5. 학습 로드맵

`Next.js → React Native → Kotlin → Flutter` 순서를 수평 타임라인으로
표현한다. 현재 단계는 Next.js로 표시하고 진행률이나 완료율은 만들지
않는다.

### 6. 편집 원칙

주간 발행 구조를 세 개의 열로 요약한다.

- 첫 영업일: 순차 학습
- 둘째 영업일: 새로 나온 기술
- 마지막 영업일: 주간 기술 심화

공휴일을 제외한 영업일 기준이라는 설명을 함께 표시한다.

## 모바일 구성

모바일에서는 다음 순서로 한 열 배치한다.

1. 대표 글 이미지
2. 대표 글 정보
3. 관심 분야
4. 최신 글
5. 학습 로드맵
6. 편집 원칙

로드맵은 가로 스크롤 대신 세로 단계로 전환한다. 모든 제목과 버튼 텍스트는
390px 너비에서 잘리지 않아야 하며, 이미지에는 고정 종횡비를 적용해 레이아웃
이동을 방지한다.

## 시각 체계

- 배경: 기존 밝은 회백색과 다크 테마 유지
- 주조색: 검정에 가까운 본문색
- 강조색: 기존 녹색
- 링크: 기존 파란색
- 보조 강조: 기존 코랄색을 편집 원칙의 작은 표식에 제한
- 모서리: 최대 8px
- 그라디언트와 장식용 구체는 사용하지 않는다.
- 섹션은 떠 있는 카드가 아니라 구분선과 배경 밴드로 나눈다.

## 데이터 흐름

1. `getPublishedPosts()`로 공개 글만 조회한다.
2. 첫 글을 대표 글로 선택한다.
3. 나머지 글을 최신 글 목록에 전달한다.
4. 실제 카테고리 집합과 관심 분야 이름을 비교해 링크 여부를 결정한다.
5. 로드맵과 편집 원칙은 홈 전용 정적 콘텐츠로 렌더링한다.

## 예외 상태

- 공개 글 0개: 대표 글 대신 발행 준비 상태를 보여주고 이미지 공간을 만들지
  않는다.
- 공개 글 1개: 대표 글만 표시하고 최신 글 영역에는 대기 상태를 표시한다.
- 대표 이미지 누락: 기존 콘텐츠 스키마 검증이 빌드를 실패시킨다.

## 검증 기준

- 공개 글이 0개, 1개, 여러 개인 경우의 데이터 분기 테스트
- 대표 글이 최신 글에 중복되지 않는지 테스트
- 존재하는 관심 분야 카테고리만 링크가 생성되는지 테스트
- `draft` 및 미래 발행 글이 홈에 노출되지 않는지 기존 테스트 유지
- 390px, 768px, 1440px에서 가로 스크롤과 텍스트 겹침이 없는지 확인
- 라이트 및 다크 테마에서 대비와 이미지 가독성 확인
- 대표 글 링크, 카테고리 링크, 메뉴의 키보드 접근성 확인

## 범위 밖

- 작성되지 않은 글의 발행 예정 카드
- 조회수와 인기 순위
- 추천 알고리즘
- CMS 또는 관리자 화면
- 기존 글 상세 페이지의 전면 재설계
